# 架构概览

- Web 前端：管理端（医生/护士/药师等工作台）
- API 网关：同后端服务（可后续拆网关）
- 应用服务：用户/权限、患者与挂号、门诊接诊、处方与药房、医技、计费结算、库存、报表
- 外部系统：LIS/PACS/医保/支付

## 上下文与事件
- 处方已审核 -> 发药拣选 (event)
- 发药完成 -> 库存出库 (event)
- 医技申请 -> LIS/PACS 下发 (event)
- LIS/PACS 回传 -> 结果入库 -> 通知医生 (event)
- 支付成功 -> 账单更新 (event)

## 安全与合规
- JWT、RBAC、数据权限、审计日志、敏感字段脱敏
- Flyway 管理 DDL，重要数据变更需审计
